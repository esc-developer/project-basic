# Project Basic (PB)

Roblox development site for esc: a UI designer (3 years' experience) from England.

## Files
- `index.html` - the page
- `style.css` - purple, blue and cyan gradient theme
- `assets/` - PB logo (transparent), favicon and wallpaper pattern

## Put it online with GitHub Pages
1. Upload everything in this folder to a GitHub repository (the `index.html` file must be at the top level).
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then save.
4. After a minute or so your site will be live at `https://<your-username>.github.io/<repo-name>/`.

To preview locally, just open `index.html` in a browser.
